# caminaPropiedades

App para iPhone y Android: caminas, ves las propiedades en venta a tu alrededor y
cada una te dice si está cara o barata frente a su sector. Todo gratis salvo el
informe en PDF.

- `api/`: API en Python que usa los datos y el motor de DossierInmobiliario. Ver [api/README.md](api/README.md).
- `app/`: la app para iPhone y Android en Expo (React Native). Ver [app/README.md](app/README.md).
